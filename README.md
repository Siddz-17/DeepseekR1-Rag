# DeepseekR1-Rag

**DeepseekR1-Rag** is an Retrieval-Augmented Generation application which analyzes documents. Built with **Streamlit**, powered by **LangChain**, **Ollama**, and **EasyOCR** , It enables seamless document and image-based question answering using advanced AI models for extracting and processing information.

## 🚀 Features

- **Document Processing:** Upload PDF files for quick extraction and analysis of content.
- **Image Analysis:** Upload JPEG or PNG images for text extraction using OCR (Optical Character Recognition).
- **AI-Powered Q&A:** Ask questions about uploaded documents or images and receive precise answers.
- **In-Memory Vector Search:** Fast similarity search with embedded document vectors.
- **Intuitive UI:** Clean, dark-themed interface for an enhanced user experience.

## 🧠 Technologies Used

- **Streamlit:** For building the interactive web app.
- **LangChain:** Handles text processing, document splitting, and chaining for Q&A.
- **Ollama:** Provides powerful language models and embeddings for document understanding.
- **EasyOCR:** Extracts text from images with high accuracy.
- **PDFPlumber:** Efficient PDF text extraction.

## 📥 Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Siddz-17/DeepseekR1-Rag.git
   cd DeepseekR1-Rag
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```

## 📄 Usage

1. **Upload a PDF or Image:** Use the file uploader to add your document.
2. **Document/Image Processing:** The app extracts content automatically.
3. **Ask Questions:** Enter your query in the chat input and receive AI-generated answers.

## 📊 Sample Workflow

1. Upload a research paper (PDF) or image (JPEG/PNG).
2. The app processes the document/image, extracting the relevant text.
3. Enter your question in the chatbox.
4. Get concise, AI-generated answers based on the document’s content.
